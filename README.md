# MusicStageTrack
A Python application that helps users track favorite music artists and organize upcoming concerts and music events.
MusicStageTrack is a Concert and Music Event Tracker that enables the user to store information on their favorite music artists, track the concerts that are coming up, and plan the music events they would like to attend.

##Project Objectives
-Save information on favorite music artists.
-Track upcoming concerts.
-Save concert date and location information.
-Plan music events the user wishes to attend.
